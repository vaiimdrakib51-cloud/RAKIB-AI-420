# NOVA AI — Complete Android Personal AI Assistant

NOVA AI is a fully functional, futuristic personal AI assistant built purely in Kotlin with Jetpack Compose, Material 3, Clean Architecture, and low-level Android automation capabilities.

---

## 🚀 Key Features

- **Continuous Voice Interaction:** Foreground listening service with Android SpeechRecognizer and TextToSpeech.
- **Multimodal AI Brain:** Powered by Google Gemini 1.5 Pro with natural multi-turn conversations and multi-command planning.
- **Phone Automation Engine:** Android `AccessibilityService` integration to perform clicks, scrolls, and text entry without coordinate dependency.
- **Floating AI Overlay:** Interactive floating bubble for over-the-app controls and quick voice inputs.
- **Offline Memory System:** Local persistence using Room Database & Jetpack DataStore.

---

## 🛠 Tech Stack

- **UI:** Jetpack Compose, Material 3, Custom Canvas & Vector Graphics
- **Architecture:** MVVM + Clean Architecture
- **Dependency Injection:** Dagger-Hilt
- **Local Persistence:** Room, Preferences DataStore
- **Networking:** Retrofit2, OkHttp, Kotlinx Serialization
- **AI / Vision:** Google Generative AI Client SDK, ML Kit OCR
- **Language Support:** English & Bengali (স্বয়ংক্রিয় ভাষা শনাক্তকরণ)
